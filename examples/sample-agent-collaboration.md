# Sample Agent Collaboration (Illustrative)

This is an example interaction pattern, not a claim these exact messages occurred live.

**Human:** Research software opportunities in a target segment.
**Coordinator:** Confirms geography, service fit, and objective.
**Lead Hunter:** Returns candidates with public evidence, URLs, dates, confidence.
**Lead Qualifier:** Scores fit/need/urgency and marks unknowns.
**Sales Strategist:** Challenges weak signals and recommends next action.
**Coordinator:** Consolidates.
**Follow-up Manager:** Drafts outreach.
**Human:** Reviews and explicitly approves/rejects sending.
**Meeting Coordinator:** Checks calendar options if requested.
**Proposal Agent:** Drafts after discovery using human-provided commercial terms.
**Human:** Approves any external action or commitment.
