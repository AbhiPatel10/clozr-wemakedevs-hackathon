# Hackathon Judge Demo Script (5–7 minutes)

1. **Introduce (30s):** CLOZR is an AI business team, not another chatbot. Specialist agents collaborate across Sales, BA, and Development; humans approve consequential actions.
2. **Sales (90s):** In `#clozr-sales`, run a small research task. Show evidence, lead score, independent challenge, outreach draft-only boundary.
3. **BA (90s):** Use fictional Nova Retail in `#clozr-ba`. Show requirements, architecture, estimate, QA, and CONFIRMED/ASSUMED/CLIENT-GATED/EXCLUDED labels.
4. **Handoff (60s):** Share actual internal handoff file in `#clozr-development`; show manager verifying access, version, and approval. If blocked, show honest blocker and resolve it—do not stage false success.
5. **Development planning (60s):** Show milestone/task plan and distinction between planning and implementation approval. State only Development Manager is currently created.
6. **Close (30s):** CLOZR connects opportunity to delivery through coordinated specialist work, traceability, and human approval.

Do not claim integrations fully verified, emails automatically sent, calendar bookings made, future specialist agents created, Nova Retail is real, draft handoff approved, or code implemented when only planning occurred.
