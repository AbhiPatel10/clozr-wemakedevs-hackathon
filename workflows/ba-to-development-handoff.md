# Workflow: BA to Development Handoff

## Required artifact
Project ID/title/owner/version/date/status; approving human; objective; scope labels (CONFIRMED, ASSUMED, CLIENT-GATED/UNKNOWN, EXCLUDED); requirement and acceptance-criteria references; architecture; estimate and basis; build sequence/dependencies; risks/open questions; QA findings; feature flags/constraints; human approval conditions.

## Transfer
1. BA Manager verifies latest version and approval state.
2. BA Manager creates/shares an actual accessible Markdown/PDF file or verified document link.
3. Share in `#clozr-development`, identifying project ID and version.
4. Development Manager opens and reads the artifact.
5. Development Manager confirms access, version, approval, and blockers before planning.

Document shared ≠ document approved. Planning approval ≠ implementation approval. Internal handoff ≠ client-facing SOW. Slack summary is notification, not source document. If inaccessible, report BLOCKED; never claim review.
